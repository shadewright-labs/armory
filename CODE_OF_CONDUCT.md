# Code of conduct

Armory follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Treat people with respect in issues, pull requests and reviews. Harassment, personal attacks, discrimination and publishing someone's private information are prohibited.

## Reporting

Use the [private reporting form](https://github.com/shadewright-labs/armory/security/advisories/new) and mark the title as a conduct report. The maintainer, [pkalin](https://github.com/pkalin), reads reports within 7 days and applies the Covenant's enforcement guidelines. Reports about a maintainer go to the other maintainers if there are any.
