# Security policy

Armory is in development. The `main` branch is the supported version until the first release.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/shadewright-labs/armory/security/advisories/new). Keep vulnerability details out of public issues and pull requests.

Include the affected package and version or commit, the impact and steps to reproduce with synthetic data. Keep live credentials and personal data out of the report.

Expect an acknowledgement within 7 days and a fix or decision within 90 days. Confirmed vulnerabilities receive a GitHub security advisory and, where applicable, a CVE. Reporters can choose whether to be credited.

## Scope

This policy covers packages and automation in this repository. Report already public dependency advisories in an issue or a pull request that updates the dependency.
